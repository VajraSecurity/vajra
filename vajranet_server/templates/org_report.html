A. About Vajra

Vajra is an open-source Endpoint Detection and Response (EDR) tool. It uses an enhanced Osquery framework to provide deep endpoint visibility and telemetry. Its rich ruleset enables detection of malware and security threats in real time, allowing security teams to take immediate action.

Provenance of the evidence. The figures in this report rest on a mixed evidence base and are not uniformly agent-verified. Three kinds of evidence are combined without being distinguished per control: telemetry collected from live Vajra agents and stored in the Vajra compliance database; platform-capability assertions, where a control records that Vajra collects, monitors or reports a class of data rather than that the endpoint is configured securely - the majority of the SEBI CSCRF and IRDAI control points are of this kind; and operator-attested answers, where a CERT-In guideline has no automated check and an administrator’s Yes/No response is recorded against every endpoint in scope. A small number of controls are additionally evaluated from platform records rather than from an agent sweep. This report should therefore not be read as an assertion that every figure below is machine-verified, nor that none of it is self-assessed.

This report consolidates the organization’s compliance posture across four frameworks: SEBI CSCRF, IRDAI cyber guidelines, CERT-In directives, and the Vajra Baseline framework. It was generated automatically on <%= generated_datetime %>. Scores are the average control pass rate per endpoint - the mean of the individual scores of the endpoints that returned results - and not the percentage of endpoints that pass every control. That count is reported separately as Fully Compliant.

When these figures were measured

No compliance figure in this report is measured while it is generated. Each framework's score, endpoint counts and distribution are read out of that framework's most recent stored snapshot, and those four snapshots were taken at four different times - none of them necessarily recent. The generation date above is the date this document was produced, not the date the endpoints were assessed, and a figure carried here from an old snapshot must not be read as a current measurement. The Assessment Snapshot Recency table in section C gives each framework's snapshot timestamp and its age at the time this report was generated; the fleet, alert and audit counts in sections B and D are the only figures read live from the database.

C. Multi-Framework Compliance
Scope of this assessment

This assessment covers Windows endpoints only. Of the <%= fleet_total %> endpoints enrolled in Vajra, <%= windows_nodes %> are Windows hosts; endpoints running any other operating system are not assessed against any of the four frameworks below and are excluded from every percentage in this section.

Each percentage is computed over responding hosts only - the Windows endpoints counted in the Endpoints Assessed column below - not over the Windows estate and not over the enrolled fleet. Windows endpoints that were offline, or that were queried and did not answer, are excluded from both the numerator and the denominator rather than counted as failing. The Windows Hosts Not Assessed column counts them: those endpoints are neither compliant nor non-compliant under that framework, and their absence must not be read either way.

These figures are therefore not an estate-wide compliance rate and must not be quoted as one. The Windows Compliance Coverage table in section B shows what fraction of the Windows hosts each framework actually reached.

F. Compliance Tier Distribution

Tier counts are written by the sweep that produced each snapshot, and the sweeps do not all classify the same unit or apply the same band edges. The Counts column states what each row is counting; rows counting different units are not comparable and must not be added together, which is why no column total is given.

Vajra Baseline classifies endpoints by their individual score: Strong ≥ 90 %, Moderate 75–89 %, Needs Attention < 75 %. CERT-In classifies controls by their fleet pass rate: Strong ≥ 80 %, Moderate 50–79 %, Needs Attention < 50 %. The SEBI CSCRF and IRDAI sweeps do not compute tier counts at all, so those rows are reported as not assessed rather than as zero.
